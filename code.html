Code

Software released with my papers and my students' work. More on GitHub.

Python

pocket-audit

Local audits of a clinical prediction model's calibration: finds groups of patients for whom predicted risks are systematically off. Code for Modenesi et al. (2026), AICCC.

Python

GraphNetz

Statistical benchmarking of graph neural networks: confidence intervals, paired comparisons with multiple-testing correction, and critical-difference diagrams. With Kleyton da Costa; methods in da Costa and Modenesi (2026), LoG.

Python (JAX)

qJAX

Machine learning with Tsallis statistics: replaces fixed choices such as the Gaussian, softmax and Shannon entropy with one learnable parameter, q. With Kleyton da Costa.

R (CRAN)

epiworldRcalibrate

Fast calibration of agent-based epidemic models with pre-trained machine learning models, for use with epiworldR. Led by Ph.D. advisee Sima Najafzadehkhoei (GitHub); methods in Najafzadehkhoei, Vega Yon, Meyer and Modenesi (2025).
